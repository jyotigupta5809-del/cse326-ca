Every donation can save up to three lives in medical emergencies.

About Local Blood Donor Directory

A student-led initiative to connect blood donors and patients seamlessly.

Our Mission

The Local Blood Donor Directory was developed as an academic practical project for the Web Technologies course (CSE326). Our vision is to build an open, accessible, and community-centered platform that eliminates the delay in finding compatible blood donors during life-threatening medical emergencies.

How It Works

1

Register or Request

Donors register to build our community pool. Patients or their relatives can submit blood requests without logging in.

2

Admin Verification

Administrators review donor applications and verify blood requests to maintain a trustworthy and secure platform.

3

Automated Matching

Our algorithm instantly pairs approved blood requests with compatible, available donors in the same city.

4

Lifesaving Delivery

Donors accept requests directly from their dashboard, and requests are marked fulfilled once donation is complete.

Academic Note: This application demonstrates client-side state persistence with HTML5, CSS3, and JavaScript using browser localStorage. No external database or backend server is required.
